# email-assets

Public images for client emails built by Renkyo. Email clients such as Gmail only show images from public https links, so the files here are served through jsDelivr:

`https://cdn.jsdelivr.net/gh/abin-renkyo/email-assets@<tag>/<client>/<file>`

Pin to a tag so emails that were already sent keep pointing at the same file.

| File | Used in |
|---|---|
| `hapsmiths/hapsmiths-logo.png` | Hapsmiths onboarding emails (official wordmark with ™, 627×135, shown at 204×44) |
